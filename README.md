## Contributing

1. Branch off `main` using the naming conventions:
   - `feat/<short-description>` — human-driven feature work
   - `claude/<short-description>` — AI-assisted work
2. Commit with concise, imperative messages: `Add login endpoint`, `Fix null check in parser`.
3. Push your branch and open a pull request targeting `main`.
4. Never commit directly to `main`.
